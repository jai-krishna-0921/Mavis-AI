# Project plan

- Goal and success measure first (one line each, measurable).
- Phases with dates and a deliverable each; 3 to 6 phases. In a deck use `timeline`; in a doc a table
  (phase, dates, deliverable, owner); in a sheet one row per task with owner, start, due, status columns
  (status values: Not started, In progress, Blocked, Done).
- Dependencies and risks called out with owners.
- Use real dates from the brief; relative dates ("week 2") only when no start date is given.

# Zento MVP — Master Implementation Plan (Index + Shared Contracts)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Read this index before any phase plan.** The contracts below are binding for every phase.

**Goal:** Build Zento, a 24×7 proactive personal-assistant agent on Telegram with graph+vector memory, an event-driven initiative engine, multi-agent orchestration with approvals, Composio-backed (temporary) integrations, a code/document sandbox, and an AWS deployment.

**Architecture:** Stateless `api` normalises webhooks into `Event`s on a bus (Redis Streams; in-process in dev). `worker` processes run the LangGraph conversation graph, the initiative agent, orchestrator tasks, learn jobs and the outbox sender. A `timer` role fires agent-owned wakeups. Business logic depends only on ports (`Channel`, `EventBus`, `IntegrationProvider`, `Sandbox`, `GraphStore`, `VectorStore`).

**Tech Stack:** Python 3.13, uv, FastAPI, LangGraph (+ checkpoint-postgres / checkpoint-sqlite), langchain-openai against Ollama Cloud, SQLAlchemy 2 async + psycopg 3 / aiosqlite, Alembic, Redis Streams (redis-py asyncio), Neo4j, Qdrant, fastembed, pyahocorasick, python-telegram-bot 21+, httpx, Tavily, E2B, Langfuse, structlog, pytest + pytest-asyncio + respx + fakeredis.

**Spec:** `docs/superpowers/specs/2026-10-02-zento-pa-design.md`

## Global Constraints

- Python `>=3.13`; dependency manager `uv`; run everything via `uv run`.
- Lint/format: `ruff` (line length 110). Types: full annotations on public functions.
- Tests: `pytest` with `asyncio_mode = "auto"`; tests never call real LLMs, Telegram, Composio, E2B or Tavily (use fakes/respx). Real-model checks live only in `zento eval`.
- LLM endpoint: `OLLAMA_BASE_URL=https://ollama.com/v1`; `MODEL_FAST=gpt-oss:20b`; `MODEL_SMART=gpt-oss:120b`. Never hardcode model names outside `config.py`.
- Every LLM output that drives a decision is a Pydantic model validated via `zento.llm.structured()`.
- Default timezone `Asia/Kolkata`; all stored datetimes are timezone-aware UTC; convert to user tz only for prompts and display.
- Ping policy defaults: daily unsolicited budget `6`; quiet hours `23:00–07:00` local; urgency `5` bypasses quiet hours.
- Single-user mode: only chat ids in `ALLOWED_TELEGRAM_CHAT_IDS` are served.
- Business-logic packages (`agents`, `initiative`, `memory`, `loops`, `policy`, `timers`) must not import `telegram`, `composio`, `e2b`, `tavily` or `httpx` directly.
- Persona name: `Zento`. Bubbles: 1–3 per reply, each ≤ 400 chars unless delivering content the user asked for.
- Telegram message hard limit 4096 chars: the channel splits longer text.
- Composio identity: `user_id = f"zento-{user.id}"`; never default to the first ACTIVE connection.
- Secrets never logged; structlog redaction processor masks keys matching `(?i)(key|token|secret|password)`.
- Files: one responsibility per module; a module over ~300 lines is a signal to split.
- Commits: conventional commits, one per task; no Co-Authored-By or any AI attribution trailers.

## Review Focus

1. **Relative times near midnight / in user tz** — "tomorrow 10am" sent at 00:09 IST must trigger a clarifying question, and "Monday 10am" must resolve to 10:00 Asia/Kolkata (04:30 UTC). Owner: Phase 3 Task "time resolution" (`zento/domain/timeutil.py`), with tests `test_ambiguous_tomorrow_after_midnight` and `test_monday_10am_ist_to_utc`.
2. **Duplicate webhook delivery** — Telegram retries the same `update_id`; the user must get exactly one reply. Owner: Phase 1 bus/idempotency task, test `test_duplicate_event_processed_once`.
3. **Rapid messages / text while an approval is pending** — two messages 200 ms apart are processed in order with the second seeing the first; free text while an approval is pending is treated as edit instructions. Owner: Phase 1 worker lock test `test_turns_serialised_per_user`; Phase 4 approval test `test_text_reply_during_pending_approval_is_edit`.
4. **Integration missing or revoked mid-task** — the run pauses and Zento prompts to connect instead of erroring; it resumes on ACTIVE. Owner: Phase 5 test `test_connection_required_interrupts_and_resumes`.
5. **LLM malformed output / timeout** — structured output invalid twice or model timeout produces a graceful "give me a sec" message and a retried job, never silence. Owner: Phase 1 LLM task test `test_structured_falls_back_then_raises_llm_error` and worker test `test_llm_failure_sends_fallback_message`.

```python
from __future__ import annotations

from datetime import datetime

from pydantic import BaseModel, Field

NODE_LABELS = ("User", "Person", "Organization", "Project", "Goal", "Event", "Topic", "Place", "Preference")
REL_TYPES = (
    "KNOWS", "FAMILY_OF", "FRIEND_OF", "COLLEAGUE_OF", "WORKS_AT", "STUDIES_AT", "PURSUING", "SUPPORTS",
    "WITH", "ABOUT", "PREFERS", "DISLIKES", "STRUGGLES_WITH", "SKILLED_AT", "LOCATED_IN", "ATTENDED",
    "INTERVIEWING_AT", "RELATED_TO",
)
SINGLE_VALUED_RELS = frozenset({"WORKS_AT", "STUDIES_AT", "LOCATED_IN"})


class Entity(BaseModel):
    name: str
    label: str = Field(description=f"One of {NODE_LABELS}")
    aliases: list[str] = Field(default_factory=list)


class Relation(BaseModel):
    subject: str = Field(description="Entity name; use 'User' for the user themself")
    rel: str = Field(description=f"One of {REL_TYPES}")
    object: str
    statement: str = Field(description="The fact as one natural sentence")
    confidence: float = Field(ge=0, le=1, default=0.8)


class ExtractedEvent(BaseModel):
    title: str
    starts_at: datetime | None = Field(description="ISO-8601 with offset; null if time unknown/ambiguous")
    ambiguous: bool = Field(default=False, description="True if the time could mean two different days")
    with_people: list[str] = Field(default_factory=list)
    importance: int = Field(ge=1, le=5, default=3)


class LoopDraft(BaseModel):
    kind: str = Field(description="COMMITMENT | WAITING_ON | GOAL | CONCERN | ROUTINE | WATCH")
    title: str
    due_at: datetime | None = None
    entities: list[str] = Field(default_factory=list)
    importance: int = Field(ge=1, le=5, default=3)


class ProfileUpdate(BaseModel):
    field: str = Field(description="name | timezone | tone | goals | key_people | routines | dislikes | other")
    value: str


class Extraction(BaseModel):
    entities: list[Entity] = Field(default_factory=list)
    relations: list[Relation] = Field(default_factory=list)
    events: list[ExtractedEvent] = Field(default_factory=list)
    loops: list[LoopDraft] = Field(default_factory=list)
    profile_updates: list[ProfileUpdate] = Field(default_factory=list)
    mood: str | None = None


class RecallContext(BaseModel):
    profile: str = ""
    loops: list[str] = Field(default_factory=list)
    facts: list[str] = Field(default_factory=list)
    episodes: list[str] = Field(default_factory=list)

    def render(self) -> str:
        parts: list[str] = []
        if self.profile:
            parts.append(f"## About the user\n{self.profile}")
        if self.loops:
            parts.append("## Open loops\n" + "\n".join(f"- {x}" for x in self.loops))
        if self.facts:
            parts.append("## Known facts\n" + "\n".join(f"- {x}" for x in self.facts))
        if self.episodes:
            parts.append("## Related past moments\n" + "\n".join(f"- {x}" for x in self.episodes))
        return "\n\n".join(parts)
```

```python
from __future__ import annotations

from zento.domain.policy import Capability


class ZentoError(Exception):
    """Base error."""


class LLMError(ZentoError):
    """Model unreachable, timed out, or produced unusable output after retries."""


class ConnectionRequired(ZentoError):
    def __init__(self, capability: Capability, reason: str) -> None:
        super().__init__(f"{capability.value} not connected: {reason}")
        self.capability = capability
        self.reason = reason


class ApprovalRequired(ZentoError):
    def __init__(self, action: str, preview: str, arguments: dict) -> None:
        super().__init__(f"approval required for {action}")
        self.action = action
        self.preview = preview
        self.arguments = arguments


class BudgetExceeded(ZentoError):
    """A task exceeded its step/token/time budget."""
```

```python
from __future__ import annotations

from collections.abc import Awaitable, Callable
from enum import StrEnum
from typing import Protocol

from zento.domain.events import Event, Job


class Stream(StrEnum):
    EVENTS = "zento:events"
    JOBS = "zento:jobs"


EventHandler = Callable[[Event], Awaitable[None]]
JobHandler = Callable[[Job], Awaitable[None]]


class EventBus(Protocol):
    async def publish(self, event: Event) -> bool:
        """Publish an event. Returns False if this event id was already seen (deduped)."""

    async def enqueue(self, job: Job) -> None: ...

    async def consume_events(self, group: str, consumer: str, handler: EventHandler) -> None:
        """Run forever, delivering events to handler; ack on success, retry ≤5 then DLQ."""

    async def consume_jobs(self, group: str, consumer: str, handler: JobHandler) -> None: ...

    async def close(self) -> None: ...
```
